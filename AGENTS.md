# Project Rules

- The hero portrait is a background-removed WebP at `src/assets/seam-portrait.webp` with its lower edge faded out in the file itself, and it must never be framed or show its original light-grey studio background. On desktop (lg and up) it stays anchored to the bottom edge of the `#home` section, beside the text; below that it sits at the top of the hero, centred, with the name and affiliation centred beneath it. It appears only in the hero. Why: the source photo is a colour headshot on a light grey studio background, so any framed or un-faded placement reads as a grey rectangle pasted onto the off-white page.
